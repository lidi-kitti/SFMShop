# Замер производительности SFMShop

Скрипт: `python src/scripts/performance_benchmark.py`.

Измерения на тех же данных (2000 заказов × 8 позиций; поиск среди 20 000 товаров). Результаты совпадают до и после, меняется только время.

| Операция | До | После | Ускорение |
|----------|----|--------|-----------|
| Сумма заказов | обход всех `items`, **0.003949 с** | сумма `order.total`, **0.001012 с** | **3.9×** |
| Поиск товара по id | список O(n), **0.001689 с** | словарь O(1), **0.000003 с** | **~600×** |

В API это же разделение: витрина берёт готовый список из Redis (`CacheService`, TTL 1 ч), а не каждый раз собирает JOIN; `GET /products` с cache hit не ходит в PostgreSQL.
